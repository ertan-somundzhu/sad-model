# sad-model
Это мой пет-проект, цель которого — создать модель SAD с нуля.



Что я сделал:
1) Написал пользовательский класс, который преобразует необработанный аудиосигнал в логарифмическую мел-спектрограмму с помощью PyTorch, чтобы можно было использовать GPU.
2) Обработал существующий датасет: взял из него выборку, так как у меня не так много вычислительных ресурсов (всё запускалось на GPU в Google Colab, и среда регулярно падала при попытке загрузить и обработать весь датасет), и преобразовал её в логарифмическую мел-спектрограмму с помощью моего пользовательского класса.
3) Успешно обучил модель на основе GRU для обнаружения речевой активности.

Более подробное описание репозитория:
* logMelSpectrogram.py — содержит пользовательский класс для построения логарифмической мел-спектрограммы
* sadModel.py — архитектура модели
* speech_detection.py — класс, отвечающий за инференс
* trainerAndTester.py — класс, содержащий циклы обучения и тестирования; я постарался сделать его как можно более применимым к другим задачам
* model_training.ipynb — ноутбук с кодом обучения модели
* data_processing.ipynb — ноутбук с кодом, с помощью которого я обрабатывал данные
* example_inference.ipynb — ноутбук, который, как следует из названия, содержит пример использования


Примечание: несмотря на то, что модель показывает довольно хорошие результаты на тестовой выборке, в реальных условиях она, вероятно, будет работать хуже, поскольку датасет vad-human-ava-speech состоит из очень чистых аудиозаписей без внешнего шума.
